# 💯 100 Days of Projects

> One hundred tiny apps. Pure vanilla JavaScript, HTML, and CSS. No frameworks, no build tools, no excuses.

This repo is a finished 100-day coding challenge — a self-contained mini-app for every day, ranging from silly toys to legit utilities, recreated classics, audio/visual experiments, and a few small algorithm playgrounds. Every project is its own folder with three files: `index.html`, `style.css`, `script.js`. Open the file. Read it. Break it. Done.

---

## 🚀 Quick start — the Hub

The fastest way to explore: open the **hub** at the repo root.

```bash
# 1. Clone
git clone https://github.com/toko-stark/100-days-of-projects.git
cd 100-days-of-projects

# 2. Open the hub (or serve it locally for projects that need fetch())
# Option A: just open the file
start index.html        # Windows
open  index.html        # macOS
xdg-open index.html     # Linux

# Option B (recommended — some projects use fetch/getUserMedia)
python -m http.server 8000
# → http://localhost:8000
```

The hub gives you:

- 🔍 **Search** — by name, tag, or day number
- 🏷 **Filter** — Games · Tools · Visual · Audio · Utility · Data
- ▶ **Preview** — each project opens in an in-page iframe, with a one-click "Open in new tab"
- ⌨ **Escape** to close the preview

## 🛠 Tech & ground rules

- **HTML / CSS / Vanilla JS** — no frameworks, no bundlers, no `node_modules`.
- **Three files per project** — `index.html`, `style.css`, `script.js`. Anyone can read it top-to-bottom.
- **One folder per day** — open it, you're running.
- **External APIs are fair game** when the point is integration (weather, jokes, recipes, QR rendering).

A few projects need permissions (`getUserMedia` for the webcam, microphone for the recorder/visualizer) — your browser will prompt.
